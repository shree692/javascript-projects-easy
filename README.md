JavaScript Easy Projects 

A collection of small beginner-friendly JavaScript projects built while learning and practicing JavaScript fundamentals.

The goal of this repository is to understand JavaScript through hands-on projects and gradually improve my web development skills.

Projects

1. Counter Application
2. Random Number Generator
3. Prime Number Checker
4. Unicode Character Value
5. Palindrome Checker App
6. Show and Hide Password
7. Email Validator App
8. Random Password Generator
9. JavaScript Carousel

Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

Purpose

This repository is part of my personal JavaScript learning challenge.

Instead of only learning JavaScript concepts theoretically, I am building small projects to understand how JavaScript works with HTML and CSS.

Through these projects, I am practicing:

- DOM manipulation
- Event handling
- Functions
- Conditional statements
- Loops
- Strings and arrays
- Input validation
- Random number generation
- Basic JavaScript logic
